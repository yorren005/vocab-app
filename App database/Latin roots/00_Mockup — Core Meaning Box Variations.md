# 🏛️ Latin Roots — Core Meaning Box Design Variations

This interactive mockup demonstrates **4 distinct design variations** for highlighting the **Core Meaning** in all Latin root dashboards and root notes (demonstrated below using the Latin root **pet** – *"to seek or ask"*).

Switch between **Light Mode** (*Scandinavian Birch Studio*) and **Dark Mode** (*Volcanic Obsidian & Magma*) in your Obsidian settings to observe how the borders, glowing magma/pine accents, and typography dynamically adapt!
