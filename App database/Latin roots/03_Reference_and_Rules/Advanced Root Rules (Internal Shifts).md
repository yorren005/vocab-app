# Advanced Root Rules (Internal Shifts & Sound Changes)

> [!abstract] 🏛️ Mastering Latin Sound Shifts
> When Latin words combine with prefixes or undergo conjugation, their internal vowels and consonants shift in regular, predictable ways. Recognizing these simple rules prevents root confusion and connects seemingly unrelated English words to the same root.

---

## 1. Vowel Weakening (The Laziness Rule / Apophony)

When a Latin root is prefixed, the stress originally shifted to the prefix. The unstressed root vowel became "weaker" and easier to pronounce.

### Rule A: Short *a* and *e* become *i* (In Open Syllables)
When the vowel is followed by a single consonant:
- **facio** (to make) -> *con-**fic**io* -> English **deficient, proficient, efficient, sacrifice**
- **ago** (to drive) -> *ex-**ig**o* -> English **exigent, navigate, litigate, prodigal**
- **cado** (to fall) -> *ac-**cid**o* -> English **accident, incident, coincide, deciduous**
- **capio** (to take) -> *in-**cip**io* -> English **incipient, recipient, principle, discipline**
- **tango** (to touch) -> *at-**ting**o* -> English **contingent, intangible, contiguous**
- **sedeo** (to sit) -> *prae-**sid**eo* -> English **preside, resident, subside, insidious**

### Rule B: Short *a* becomes *e* (In Closed Syllables)
When the vowel is followed by two consonants or a consonant cluster:
- **factus** (made) -> *con-**fect**us* -> English **confection, infection, perfect, defect**
- **captus** (taken) -> *ac-**cept**us* -> English **accept, intercept, reception, deceptive**
- **damno** (to harm) -> *con-**demn**o* -> English **condemn**
- **scando** (to climb) -> *a-**scend**o* -> English **ascend, descend, transcend**

### Rule C: Diphthong *ae* becomes long *i* (*ī*)
- **caedo** (to cut, kill) -> *oc-**cīd**o* -> English **homicide, pesticide, suicide, decision, precise**

## 2. The Two-Stem Verb System

Every classical Latin verb produces **two primary stems** that enter English:

| Verb Source            | Stem 1: Action / Present Stem | English Words                  | Stem 2: Result / Supine Stem | English Words                        |
| ---------------------- | ----------------------------- | ------------------------------ | ---------------------------- | ------------------------------------ |
| *scribere* (to write)  | **scrib-**                    | describe, inscribe, transcribe | **script-**                  | manuscript, transcript, prescription |
| *agere* (to drive/do)  | **ag-** (*-ig-*)              | agent, agile, navigate         | **act-**                     | action, actor, reaction, exact       |
| *capere* (to seize)    | **cap-** (*-cip-*)            | captive, anticipate, capable   | **cept-**                    | concept, exception, reception        |
| *cedere* (to yield/go) | **ced-**                      | concede, precede, recede       | **cess-**                    | access, process, succession          |
| *mittere* (to send)    | **mit-**                      | transmit, emit, permit         | **miss-**                    | mission, missile, transmission       |
| *videre* (to see)      | **vid-**                      | provide, evident, video        | **vis-**                     | vision, visible, television          |
| *tendere* (to stretch) | **tend-**                     | extend, intend, pretend        | **tens- / tent-**            | tension, intense, extent, intent     |
|                        |                               |                                |                              |                                      |

## 3. Consonant Assimilation (Prefix Blending)

To make speech smoother, the final consonant of a prefix often adapts to match the first consonant of the root:

| Prefix   | Base Meaning    | Rule                                                                               | Example Before Assimilation                                         | Assimilated English Result               |     |
| -------- | --------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------- | ---------------------------------------- | --- |
| **ad-**  | to, toward      | *ad-* becomes *ac-, af-, ag-, al-, an-, ap-, ar-, as-, at-*                        | *ad- + cede* -> **accede**<br>*ad- + fer* -> **affair**             | **accept, announce, applaud, attract**   |     |
| **con-** | with, together  | *con-* becomes *col-* (before *l*), *com-* (before *b, p, m*), *cor-* (before *r*) | *con- + labor* -> **collaborate**<br>*con- + ponere* -> **compose** | **collect, compute, correct, correlate** |     |
| **in-**  | into / not      | *in-* becomes *il-* (before *l*), *im-* (before *b, p, m*), *ir-* (before *r*)     | *in- + legal* -> **illegal**<br>*in- + mortalis* -> **immortal**    | **illuminate, impossible, irregular**    |     |
| **sub-** | under           | *sub-* becomes *suc-, suf-, sug-, sum-, sup-, sur-, sus-*                          | *sub- + fer* -> **suffer**<br>*sub- + port* -> **support**          | **succumb, suggest, summon, suppress**   |     |
| **ob-**  | against, toward | *ob-* becomes *oc-, of-, op-*                                                      | *ob- + cur* -> **occur**<br>*ob- + ponere* -> **oppose**            | **occasion, offend, oppress**            |     |

## 4. Rhotacism (*s* -> *r* Shift)

In early Latin, an **s** sitting between two vowels naturally shifted to an **r**. This explains why some noun roots show an *s* in the nominative but an *r* in English derivatives:
- *flos* (flower) -> genitive *floris* -> English **floral, florist, flourish**
- *corpus* (body) -> genitive *corporis* -> English **corporation, corporeal**
- *genus* (kind/origin) -> genitive *generis* -> English **generate, general, generic**
- *opus* (work) -> genitive *operis* -> English **operate, opus, operation**
