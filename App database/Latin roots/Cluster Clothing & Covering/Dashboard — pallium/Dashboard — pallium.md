## ⚙️ 2. Root Characteristics & Word Formation Engine

> [!abstract] 🔨 Morphological Engine & Stem Evolution
> The root **pallium** generates derivatives in English across two primary stems:
> - **Nominal Substantive Stem (`pall-` / `pallium`):**
>   - Direct learned borrowings: [[pallium]], [[pallial]] (malacology and neuroanatomy).
>   - Old English direct borrowing: Latin *pallium* → Old English *pæll* ("rich purple cloth") → Modern English [[pall]] (funeral cloth, dark canopy) → [[pallbearer]].
>   - Evolutionary neuroanatomy compounds: [[neopallium]] ("new mantle" / neocortex), *archipallium*, *paleopallium*.
> - **Denominative Verbal Stem (`palliā-` / `palliāt-` < Latin *palliāre* "to cloak"):**
>   - Verb: *palliat- + -e* → [[palliate]].
>   - Action / State Noun: *palliat- + -ion* → [[palliation]].
>   - Adjective / Medical Substantive: *palliat- + -ive* → [[palliative]].
>   - Agent Nouns & Adjectives: [[palliator]], [[palliatory]], [[palliating]].
